## 2024-10-18 - [React.memo and inline functions]
**Learning:** When using `React.memo` to optimize rendering of list items (like `CaseCard`), you must ensure that all function props passed to the component are referentially stable. If you pass an inline arrow function (e.g. `onSelect={() => handleSelect(item)}`), `React.memo` will fail to prevent re-renders because the inline function is recreated on every render cycle of the parent. We need to define `onSelect` on the list item component to accept the item data so we can pass the stable `handleSelect` directly, or extract the item into a memoized container component. Also `useCallback` needs all dependencies to ensure correctness without stale closures.
**Action:** Always verify that components wrapped in `React.memo` receive stable references for function props. Refactor child component props to take parameters directly instead of using inline arrow functions in the parent's `map`.
