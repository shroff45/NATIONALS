## 2024-12-05 - Optimize React array filtering\n**Learning:** In React functional components like `OrdersHistory.tsx` and `VirtualMootCourt.tsx`, filtering arrays inside the render function without `useMemo` creates unnecessary derived state recalculations on every re-render (e.g. searching, hover states). For `VirtualMootCourt.tsx`, repeated calls to `.filter()` on the same array during rendering (e.g., `transcript.filter(t => t.speaker === 'prosecution')` evaluated 3 times) is especially costly for long transcripts.\n**Action:** Use `useMemo` to compute filtered arrays outside the immediate return statement and reuse them, preventing redundant array traversal.
