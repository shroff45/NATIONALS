## 2024-10-19 - [React.memo Optimization]
**Learning:** When using `React.memo` on a child component to prevent unnecessary list item re-renders (like in `CaseCard`), you must also ensure the parent component passes stable function references as props. If you pass an inline arrow function like `onSelect={() => handleSelect(item)}`, `React.memo`'s shallow comparison will fail every render because a new function is created, defeating the purpose of the optimization. The correct approach is to pass the uninvoked function reference `onSelect={handleSelect}` and handle the invocation (along with passing the required arguments like the `item`) from within the child component itself.
**Action:** Always verify the stability of prop references passed down from the parent when wrapping a component in `React.memo`.
