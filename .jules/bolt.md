## 2024-05-18 - Repeated O((V+E)*C) Graph Cycles Evaluation
**Learning:** Found an anti-pattern in the Financial Trail Analyzer where `networkx.simple_cycles` was called inside a loop over nodes. `simple_cycles` is an extremely expensive O((V+E)*C) operation, where C is the number of simple cycles, which can be exponential in dense financial networks. Calling it iteratively for every high-connectivity node causes an O(N * (V+E)*C) time complexity leading to performance degradation or timeouts on large datasets.
**Action:** Always extract and cache expensive graph traversal or algorithm results (like cycles, paths, or centralities) outside loops if the underlying graph structure is not being modified. Use lazy evaluation (`if result is None:`) inside the loop if the calculation is only needed conditionally to save initialization costs when no nodes meet the condition.
