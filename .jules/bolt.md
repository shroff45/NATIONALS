
## 2024-11-05 - [React.memo and Object Prop Patterns]
**Learning:** Applying `React.memo` to a list item component like `CaseCard` is necessary for performance when rendering large arrays (O(N) rendering). However, if an inline function like `onClick={() => onSelect(item)}` is passed from the parent within a `.map` loop, or if an inline anonymous function like `onSelect={() => handleSelect(item)}` is given to the item component, it generates a new function reference every render and completely defeats `React.memo()`. The parent's `handleSelect` must be wrapped in `useCallback()`, and the list item component itself must internally take care of the inline call, e.g., by changing its prop signature to `onSelect: (item: ItemType) => void` and invoking `onClick={() => onSelect(item)}` within its memoized body.
**Action:** Always verify the prop references when applying `React.memo` to child components within loops. Ensure functions are memoized via `useCallback` in the parent and avoid inline functions in the mapped properties.
