## 2024-05-15 - [useMemo for derived array optimization]
**Learning:** In frontend list components (e.g., `CaseQueuePage.tsx`, `EvidenceVault.tsx`, `SmartBailPage.tsx`, `BenchMemoTemplates.tsx`, `OrdersHistory.tsx`, `CitizenTimeline.tsx`), the `filteredCases` and similar derived arrays are often computed synchronously on every render, even when the underlying data (`MOCK_QUEUE`, etc.) or filter parameters have not changed. While not a massive bottleneck for small mock data, missing `useMemo` is a typical performance antipattern. Additionally, repetitive `.toLowerCase()` operations inside the `filter` loop could be slightly optimized by hoisting the `.toLowerCase()` call outside.
**Action:** When working on frontend list performance, wrap derived state in `useMemo` and hoist redundant calculations (like search query lowercase transformations) outside the `filter` callback.
