## 2024-05-18 - Missing useMemo in React filter lists
**Learning:** Found that list components in this codebase (like `CaseQueuePage.tsx`, `EvidenceVault.tsx`, `SmartBailPage.tsx`, `BenchMemoTemplates.tsx`, `OrdersHistory.tsx`, `CitizenTimeline.tsx`) recalculate filtering on every render because they do not use `useMemo`. This creates a performance bottleneck when filtering is performed across larger case lists or with typing search inputs. `CaseQueuePage.tsx` re-evaluates `MOCK_QUEUE.filter` and `.toLowerCase()` inside the component body, which means every keystroke in search triggers full list traversal without memoization. Furthermore, doing `.toLowerCase()` inside the filter iteration loop multiple times is inefficient.
**Action:** When working on list components, explicitly use `useMemo` for derived data arrays like `filteredCases`, specify the dependency array, and hoist repetitive operations like `.toLowerCase()` out of the loop if applicable to optimize React performance and prevent unnecessary re-renders.
